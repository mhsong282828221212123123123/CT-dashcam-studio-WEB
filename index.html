홈 화면 바로가기 추가

CT Dashcam Studio
앱처럼 전체화면으로 즉시 실행
PC 데스크톱 (Windows / Edge / Chrome)
  1. 브라우저 상단 주소창 우측 끝의 앱 설치( ⊕ 또는 ) 아이콘을 클릭하거나,
  2. 브라우저 메뉴(⋯ 또는 ⋮) '앱' 'CT Dashcam Studio 설치'를 선택하세요.
  3. 설치 팝업에서 '바탕 화면 바로 가기 만들기'를 체크하면 바탕화면에 앱 아이콘이 바로 생성됩니다!
안드로이드 (Galaxy / Chrome / 삼성 인터넷)
  1. 아래 [ 즉시 바로가기 추가] 버튼을 누르거나,
  2. 브라우저 상단/하단 더보기(⋮ 또는 ≡) 메뉴 탭
  3. '현재 페이지 추가' 또는 '홈 화면에 추가'를 선택하세요.
아이폰 / iPad (Safari)
  1. 사파리 하단 중앙의 공유 버튼( ) 탭
  2. 메뉴를 아래로 스크롤하여 '홈 화면에 추가 (+)' 탭
  3. 우측 상단 '추가'를 누르면 홈 화면에 바로가기 생성!
